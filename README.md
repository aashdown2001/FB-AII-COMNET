The raw data collected on Colosseum for ST-FB-AII can be found in the ST-FB-AII/ folder.

To get the MT-FB-AII data used in the paper, follow this proceedure:

1. Open MT-FB-AII/

2. Run test-script.py (this could take a few hours)

3. Once test-script.py has finished running, run average_json_master.py inside data/

4. Run compare.py inside data/ to get numerical results

5. Run master-plot.py inside data/ for timeseries plots and bar.py inside data/ for barchart
